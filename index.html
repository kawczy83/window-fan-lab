How the model works: cooling speed is driven by the air-exchange rate. The biggest factor is whether a complete intake → exhaust path exists. A sealed fan stalls itself — the one-in/one-out rule. Open or close each window independently; with multiple openings available, the model draws the dominant pressure-assisted path. For the default wind toward South, a South-window exhaust can pull from a windward North window.

Shared environment

Reading the result: a clean through-path (fan + at least one other open window) cools fast; isolating the fan stalls it. Race timers are relative simulation time, not calibrated elapsed seconds. Out vs In is usually close once both have a path. Opposing wall presets make the wind-pressure effect easiest to compare.
